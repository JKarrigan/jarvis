# Audit and fix pass — 31 October 2026

Five read-only audits (server security, air-quality core, media/Jellyfin, lights +
file browser + deploy, front-end/accessibility/Next 16 conventions) followed by a
fix pass split by file ownership, plus the new Photos library
(`photos-spec.md`). Branch: `feat/audit-fixes-and-photos`.

## What was wrong (highest impact first)

| Area | Finding | Fix |
|---|---|---|
| Files | `DELETE /api/files/delete` with no `path` resolved to the storage root and ran `rmSync(FILES_ROOT, { recursive: true })`. Rename/move accepted the root too. | `resolveEntry()` refuses the root (403), missing path → 400, separator-aware and realpath checks (`lib/files.ts`). |
| Media | The Jellyfin access token (the admin API key in `JELLYFIN_API_KEY` mode) was embedded in every stream URL sent to browsers. | All streams and images go through `app/api/jellyfin/stream/[...path]`; the token never leaves the server. |
| Media | "Delete collection" called `DELETE /Items/{id}` on any id, so it could delete a movie from the NAS. | Item type is checked (`BoxSet`) before delete/rename; ids validated. |
| Air | Event detection ran in the browser over a sliding buffer, minting a new event id every 10 s: one 2 h CO₂ episode produced 613 ids; Dismiss never stuck; four events had been "ongoing" since May. | Detection moved into the server poller as one incremental detector with stable ids and a baseline frozen at onset; reprocess keeps acknowledgements. |
| Air | The poller only started when a browser POSTed the device IP, so nothing was logged after a reboot or deploy until someone opened the app. | `instrumentation.ts` → `lib/startup.ts` starts the poller from the saved host at boot; hourly pruning. |
| Air | `/api/history` had no cap: 30 days = 259k rows ≈ 74 MB JSON parsed on the Pi, and `Math.min(...vals)` crashed the page above ~65k points. | SQL downsampling (≤ 800 points, cached), loop min/max, `error.tsx`. 30 d: 650 ms cold / 4 ms warm. |
| Air | Dashboards re-rendered twice a second (two 1 s clocks at the top level, no memoization). | `useNow` + `<Clock/>`, memoized charts/cards, memoized context. |
| Video | ffmpeg output was pushed into the response with no backpressure (whole remux buffered in RAM → OOM on the Pi); wrong `Content-Length`; `endOfStream()` never called so every video ended in a "keeps stalling" error. | Pull-based stream, kill on abort, 2-transcode semaphore (503 + Retry-After), chunked body, client queue bounds + `endOfStream`. |
| Uploads | No size limit; existing files silently overwritten; client aborts left the handler hanging with leaked descriptors. | busboy limits, `.part` temp files with `wx`, no-clobber commit (409 → "Keep both"), `pipeline()` so aborts propagate. |
| Deploy | The Pi hook ran `npm ci --omit=dev` then `next build`, but Tailwind/TypeScript are devDependencies, so the build could not succeed; `set -e` then skipped the PM2 restart with `node_modules` already replaced. | Full `npm ci`, build, prune, `pm2 startOrReload ecosystem.config.cjs`; new `ecosystem.config.cjs`. **Untested on the Pi (unreachable today).** |
| Lights | Hue v1 returns HTTP 200 with `[{error}]` bodies; the app treated them as success and the UI drifted. The bridge SSE link had no keepalive/timeout, so it died silently after bridge reboots. | Error bodies parsed → 502 + UI rollback; keepalive, idle watchdog, backoff; subscriber cleanup and heartbeats on the fan-out. |
| CSRF | Every mutating route was callable cross-site from any web page (no auth, no Origin/Host check), chained with inline SVG from the app origin. | `assertSameOrigin` on every mutating handler; `nosniff` + sandboxed/attachment SVG. |
| Front-end | No `loading`/`error`/`not-found` pages; Jellyfin outage looked like an empty library; mobile media had no Search and the Back pill covered the app switcher; no reduced-motion handling; hazardous colour 2.5:1; dialogs without roles/focus traps. | All added; shared accessible dialog primitives; 6-slot mobile bar with Search and Photos; `#e11d48`; `MotionConfig`. |
| Hygiene | README boilerplate, no tests/CI/`.env.example`, lint failing (21 errors), four fonts on every route, create-next-app icons. | README, Vitest (24 tests for `lib/http.ts`), GitHub Actions, `.env.example`, lint clean, per-app fonts, PWA manifest/icons. |

Full per-finding detail (file:line, failure scenarios) lives in the audit transcripts;
the fixes are described in CLAUDE.md where they changed architecture.

## Not verified on real hardware

- The Pi deploy (`scripts/pi-setup.sh`, `ecosystem.config.cjs`) — the Pi was unreachable.
- Anything against the real Jellyfin server: HLS through the proxy, the BoxSet check,
  the favorite/played endpoints on this Jellyfin version, `unstable_cache` sizes on
  the real library. Mock mode was used.
- The real Hue bridge (a fake v1 bridge was used).
- The NAS mount for Photos; the Pi's ffmpeg must be ≥ 7.1 for iPhone HEIC thumbnails
  (Debian bookworm ships 5.1).
- First production start prunes readings older than 30 days (the policy that already
  applied on every `/api/history` call) and closes the four stuck events.

## Deliberately left for later

- Favourites/watched now sync to Jellyfin, but ratings, notes, watchlist and theme are
  still per-browser `localStorage`.
- No touch "Move to…" in the file browser (drag only).
- Search modal does not include photo albums yet.
- Build still happens in place on the Pi; `output: 'standalone'` with a release
  directory swap would remove the mid-deploy window.
- No face/object recognition or automatic phone backup for Photos.
